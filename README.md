# 太阳系 · 星历与真实尺度

浏览器太阳系展示：太阳、八大行星、月球与四颗伽利略卫星，UTC 星历、双层视图、低干扰轨道、标签追焦、真实半径/增强半径、分层材质、地球夜光与大气、表面流动效果和纯净模式。

## 启动（Windows PowerShell）

需要 Node.js 22.18+（开发机使用 24）、npm。C 测试还需要 PATH 中的 GCC 和 PowerShell。

```powershell
Set-Location 'D:\solar system stimulate'
npm ci
npm run dev
```

打开终端显示的本地地址。请先切换到项目目录，不要在 `C:\Users\...` 下直接执行 npm 命令。

```powershell
npm run check
```

该命令执行前端回归、C 数值测试、TypeScript 检查和生产构建。生产文件在 `web/dist`；`npm run preview` 可预览构建产物。`?diagnostics=1` 可查看帧间隔与绘制调用统计，默认界面不显示。

## 操作

- 界面：顶部导航为“太阳系观测 / 引力实验 / 天文奇观”三段模式切换，其下是“太阳系 | ＜天体名＞”视图范围开关；左侧为天体目录（含搜索框，地球、木星右侧箭头展开卫星）；右侧卡片为“视角中心”和天体数据；底部控制栏包含播放/暂停、“现在”、速度滑块、“真实比例 / 视觉增强”分段控件、图层设置和纯净视图按钮。
- 概览默认锁定太阳中心；“视角中心”是树状菜单，主列表为太阳与八大行星，有卫星的行星可展开，也可选择“自由浏览”。滚轮始终以所选天体为中心连续缩放，右键（触屏单指）绕中心旋转；只有鼠标左键平移拖拽才会解除锁定并进入自由浏览。近景同样使用左键平移、右键旋转，最大放大停在完整圆盘接近屏幕边缘的位置。
- 点名称/天体：先把它设为概览锁定中心，再进入近景；在近景中再点另一个天体同样会改为锁定新天体。不会自动修改增强开关。向外滚轮、Esc 或顶部“太阳系”开关退出后，回到进入近景前保存的概览距离，并以最后查看的天体为中心。
- 速度滑块最左侧为“静止”：不推进星历，也不会自动同步当前 UTC；向右按天/秒加速推进星历日期。把滑块从右侧拖回最左侧只是停在当前显示的时刻，天体保持原位，不会跳回真实位置。
- 暂停冻结星历于当前显示时刻；恢复播放后从原速度继续（速度为 0 时仍保持静止）。“现在”按钮不论播放状态均可点击，会让星历时刻连续过渡回真实当前 UTC，天体随之平滑沿各自轨道滑回当前位置，随后恢复原来的播放/暂停与速度状态。
- 视觉增强：保留每颗行星的星历方位，只放大天体并重新分配到太阳的距离——每颗行星按其圆盘、星环或卫星系统占用的范围排布，相邻系统互不重叠，空隙向外逐渐变宽；卫星紧凑环绕母星，放大到该行星系统后才显示卫星名称。真实比例概览的距离始终压缩并明确标记，不能拿屏幕距离做物理测量。
- 六项真实天象（日环食、日全食、月全食、水星凌日、木星冲日、火星冲日）会在时间飞行后降到对应地面观测点。太阳、月球和行星方位使用星历；地面/海面、大气、月食红色为视觉渲染，不是实拍。左下角可调流速、重播、回正、看地平线或离开，Esc 同样离开。太阳日珥和木星大红斑仍用近天体视角。
- U 进入/退出纯净模式；Esc、双击空白/画布可恢复，触屏实现了双击恢复。
- 月球与伽利略卫星为同步自转：经度 0（平均星下点）始终朝向母星。
- 右上角时钟显示北京时间（UTC+8）；“数据”工作区仍给出 UTC。
- 近景使用凹凸/法线地表、粗糙度差异、独立云壳和受太阳方向约束的大气边缘。地球暗面叠加 NASA Black Marble 夜光观测；云层、等离子体、气流与环粒子属于视觉示意，与星历时钟分开。木星大红斑保持原始贴图形态，只做局部纹理平流。

## 当前边界

浏览器使用 Astronomy Engine 的自然星历位置。独立的 C17 N 体内核（太阳、八大行星、月球与伽利略卫星共 14 个天体，牛顿引力 + 地球/木星 J2 扁率，4 阶辛积分，JPL Horizons 真实初值，30 天内与 JPL 相差：行星约 1 km 以内，水星 9 km，木卫一 80 km）已有数值回归，但 **尚未接入网页**；质量倍率实验、引力势平面与旅行工具尚未完成。金星暂无独立纹理，自转轴/纹理经度未做精密标定。星历估算与视觉特效不应描述为实时观测图像。
