## 后期规划：原生 UI 采用 Apple Liquid Glass

适用阶段：原生客户端（Apple 平台 SwiftUI 外壳）与后续 Unreal UMG 界面层。Web 测试台继续使用现有 `backdrop-filter` 近似实现，不追求像素级复刻。

- [ ] **分层原则**：玻璃材质只用于浮在内容之上的功能/导航层（顶部模式切换、视图范围开关、底部时间控制栏、图层菜单、侧栏卡片外壳），3D 星空与天体内容层不使用玻璃；克制使用，避免满屏玻璃。
- [ ] **变体选择**：默认 `regular`；仅在背景为高亮媒体内容（如日食太阳、明亮行星近景）上方的控件使用 `clear`，并叠加约 35% 暗化层保证可读性。
- [ ] **禁止玻璃叠玻璃**：菜单/弹层在玻璃栏上方时改用普通填充或合并为同一玻璃容器。
- [ ] **着色只表达主次**：仅主操作（播放/暂停、进入奇观）使用 `tint` / `.glassProminent`，其余控件保持中性。
- [ ] **形状与边缘**：圆角与容器同心（concentric）；可滚动列表（天体目录、数据笔记）使用滚动边缘效果（scroll edge effect）代替硬分隔线。
- [ ] **SwiftUI API 映射**：`glassEffect(_:in:)`、`Glass.regular / .clear / .identity`、`.tint()`、`.interactive()`；同组控件放入 `GlassEffectContainer`，相邻按钮用 `glassEffectUnion` 融合；展开/收起用 `glassEffectID` + `@Namespace` 与 `GlassEffectTransition` 做形变过渡；按钮使用 `buttonStyle(.glass)` / `.glassProminent`。过渡期如需保留旧外观，使用 `UIDesignRequiresCompatibility`。
- [ ] **无障碍**：跟随系统“降低透明度”（回退为不透明填充）、“增强对比度”（加描边/提高前景对比）与“减弱动态效果”（关闭形变与弹性动画）；三项都需实测。
- [ ] **Unreal 映射**：UMG 中以背景模糊 + 折射/高光材质近似，遵循上述同一分层与无障碍规则；具体材质方案在接入 Unreal 时另立 ADR。

## 远期可选（优先级最低）：Windows / Unreal 复刻 Liquid Glass 观感

仅在核心功能全部完成后考虑，随时可以砍掉。Windows 没有系统级 Liquid Glass，只有 Fluent 的 Mica / Acrylic（纯模糊 + 着色 + 噪点）。

- [ ] **目标档次**：只做“神似”（毛玻璃 + 边缘折射 + 动态高光 + 按下形变），不做完整复刻（控件融合/分裂、自适应明暗全套），投入产出比太低。
- [ ] **实现路线**：玻璃下方是本项目自己渲染的星空，可直接采样场景颜色；以圆角矩形 SDF 求边缘法线做折射偏移，菲涅尔 + 光照方向做边缘高光，多个面板 SDF 用 smooth-min 合并近似 `glassEffectUnion`。UMG 用 `BackgroundBlur` 做模糊，折射通过“面板矩形参数 → 后处理材质”或“场景渲染到纹理 → UI 材质采样”实现。
- [ ] **平台习惯**：标准 Windows 窗口（设置、启动器等）使用 Mica，Liquid Glass 风格只用于覆盖在 3D 场景上的界面层。
- [ ] **性能与无障碍**：玻璃面板少而精；沿用上文的降低透明度 / 增强对比度 / 减弱动态效果回退。
