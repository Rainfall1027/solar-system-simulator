# 日食光学展示

## 参考与边界

- [NASA：月缘、贝利珠与钻石环](https://science.nasa.gov/solar-system/skywatching/eclipses/solar-eclipses/2024-solar-eclipse/total-solar-eclipse-2024-the-moons-moment-in-the-sun/)：月球山谷允许最后的阳光穿过；不是月面金属反光。
- [NASA：贝利珠实拍](https://science.nasa.gov/resource/baileys-beads/)：接触前后局部不均匀的强光，而非一圈固定高光。
- [NASA：日食类型](https://science.nasa.gov/eclipses/types/)：全食遮住光球后，日冕才容易看见；环食留下的是太阳光球的亮环。
- [NASA：太阳结构](https://science.nasa.gov/sun/facts/)：光球、色球、日冕属于不同层次，色球偏红、白光日冕具有向外延伸的结构。
- [NASA APOD：2018-02-09](https://apod.nasa.gov/apod/ap180209.html)：日食合成照片中，地球反照可显出极暗月面细节。

本项目采用**暖黄色、压缩动态范围的摄影式示意**。统一色调、持续微弱外晕及略增强的地球反照是展示选择，不宣称等同肉眼所见或严格辐射计量。真实观测日环食和偏食仍需合适太阳滤镜。

## 实现

太阳和月球的角半径、相对位置、遮挡率和接触时间仍取自原有 Astronomy Engine 星历，未调整时间线或轨道。

`ground-sky.ts` 的太阳食场景使用一个统一的光学合成着色器，而不是先后覆盖两张纯色圆片：

1. 从投影坐标恢复解析球面法线；太阳加入临边昏暗和低对比度细颗粒，月球以球面经纬度采样已有反照率和高度纹理。
2. 月缘叠加稳定且小于半径 0.13% 的程序化起伏；它只是地形示意，没有接入 LRO 实测月缘，也未做精确天平动配准。
3. 使用同一个月缘边界遮挡太阳；`eclipse-optics.ts` 在 CPU 计算 96 个露出的太阳边缘光源。露光方向变化会改变辉光方向；被完全遮挡的光球不会凭空产生直射光斑。
4. 在遮挡完成后叠加多尺度光学扩散，允许少量暖光柔和溢入月缘。它表示成像辉光，不是给月球添加金属反射或大气层。
5. 日冕持续存在，以遮挡率连续改变可见强度。环食只留微弱背景日冕，主要光晕来自未被遮挡的光球；全食以日冕为主。播放用实时时间平滑，拖动定位直接显示对应状态。
6. 输出进行柔和高光压缩，远端用径向衰减归零，避免方形面片边界。

月食场景继续使用原渲染路径。UI、时间控制、太阳系场景均不在这次改动范围内。

## 回归检查

`web/tests/eclipse-optics.test.ts` 检查日冕连续性、地形周期性和幅度、全食无直射辉光、环食完整亮环，以及亮弧随月球偏移移动。浏览器还需检查实际 shader 编译、近远景、接触前后和时间轴回拖。
