# 全项目检查与优化（2026-09-21）

## 本次范围与验收约定

对照两份项目计划及后续用户确认的双层视图、太阳中心旋转、名称追焦、真实时间、自转、太阳表面效果、纯净模式和增强模式隐藏轨道要求，检查已有实现。此次跨 C 核心、Web 展示和文档，保留 SI 单位、天体 ID 和 C 接口；不将尚未接入的 WASM、质量实验、势场、旅行工具标记为完成。

影响范围：`core/src`、`core/tests`、`web/src`、`web/index.html`、前端数学回归测试与项目文档。保留现有未提交内容和暂存区，不自动提交或推送。

## 检查发现

- 标签使用固定世界空间偏移 0.18，远大于真实地球半径；旋转后标签不一定在屏幕上方。
- 固定近景最小距离、相机近裁剪面与退出阈值不适用于大小相差极大的天体；切换增强比例不调整近景相机。
- 图层立即切换，镜头在线性插值期间仍被 OrbitControls 的残余阻尼干扰。
- 近景仍使用全太阳系点光源及阴影范围，外行星照明与精细阴影不可用。
- 土星环与球体一起自转，导致倾斜环面错误翻动。
- 纯净模式只屏蔽父元素鼠标事件，标签仍可被点击、Tab 聚焦；没有触屏退出入口。
- 每帧更新 DOM 时间、隐藏标签及全太阳系点光源的六面阴影，存在可避免的开销。
- 概览压缩距离却显示“严格真实比例”；状态与验收文档未同步后续交互要求。
- C 全系统初态未平衡总动量；日地两体的相对圆轨道速度因太阳反冲而重复增加；非有限步长会污染状态。

## 验证计划

运行 C 数值回归、前端比例/自转/相机/转场数学回归和生产构建；浏览器检查标签点击、拖拽、退出、增强切换、现实速度及纯净模式。补充实测记录，明确无法验证的内容。

- 5 项前端数学/数据一致性回归与生产构建通过。三维库独立缓存，业务包约 18.74 kB（未计下一轮星历与特效）。
- 浏览器逐个验收九天体追焦及返回；地球增强开关保持取景、滚轮退出正常。
- 580×552 窄屏与 1440×900 桌面检查，已调整面板排列与概览取景。取景变化前天王星被面板遮挡的问题已修正并复测。
- 1440×900 开发预览实测样本：帧间隔 p50 6.1 ms / p95 6.2 ms；普通行星近景 1 次绘制，主线程 p50 0.1–0.2 ms；土星近景主线程 p50 约 0.4 ms。仅为当前开发机样本，不是全设备性能承诺；主线程耗时不含 GPU 完成时间。

## 最终结果

- `npm run check` 通过：10 项前端测试、C 两体/九体年度数值回归、TypeScript 检查和 Vite 生产构建；`git diff --check` 无空白错误（仅 Windows 换行提示）。
- 四个天体与 NASA JPL Horizons 的 2026-09-21 00:00 UTC 太阳中心矢量核对通过，参考响应及误差记录在 `web/tests/horizons-reference.json`。日内缓存插值的抽样误差小于 20 km，不代表对真实星历的绝对精度。
- 默认现实速度同步 UTC；浏览器实测暂停保持时刻、恢复追上当前时刻。加速模式沿星历推进，不采用虚构初相位圆轨道。
- 太阳黑子与局部流丝、地球独立云层、气态行星纬向流动、6000 个土星环 GPU 粒子已接入。气态流动采用双相循环，避免长时间累积拉伸。仅近景启用详细特效。
- 浏览器验证太阳、地球、土星和其他气态行星的着色器与取景；最终复测无新增控制台警告/错误。视觉效果不等于实时太阳活动、气象或真实粒子动力学。
- 追加 390×844 窄屏复测，修复概览远裁剪造成的空画面，以及可用宽高被重复折减导致天体过小的问题；保留近景标签空间。测试后恢复浏览器默认尺寸。
- 概览拥挤标签纵向避让，横向位置保持投影锚点，用延伸连线指向星体；近景保持单标签。纯净模式、退出和双层切换已验证。
- 修复液态玻璃面板在太阳前产生矩形泛光的合成问题，模糊限制在裁剪的伪元素内。
- 最终业务包 28.68 kB、星历包 44.09 kB（未压缩）；当前开发机近景样本帧间隔 p50 约 6.1 ms / p95 约 6.2 ms，地球两次绘制，主线程约 0.3–0.4 ms。尚未进行低端 GPU/真实触屏设备验收。

- 移除太阳着色器的高频脊线遮罩，避免贴近表面时出现白色胞状边界；保留低频、非白色的流动亮度变化与黑子细节。
- 太阳近景加入两处尺度不同的小型日珥，每组由多股红橙色等离子弧构成，根部贴合光球层并带流动、呼吸动画；默认近景不显示，继续放大到约五个太阳半径内才渐显。
- 概览不再使用固定 `minDistance = 8`。锁定太阳或任一行星后，最小距离与该天体显示半径联动，可连续缩放至近表面；滚轮和右键旋转保持锁定，只有左键平移拖拽才切换自由浏览。
- 标签去除边框，并在相机距离超过概览基准约 1.12 倍后平滑淡出，1.42 倍后完全隐藏且不可聚焦；拉近后恢复。

- 水星、地球和火星使用贴图驱动的顶点位移与凹凸细节；地球额外使用海陆粗糙度差异。气态巨行星使用较轻的云带凹凸，避免保持为完全光滑的贴图球。
- 金星和地球云层抬离主体表面并提高差速流动幅度；金星、地球、火星及四颗巨行星增加独立的边缘大气层。后续移除跟随镜头的补光，近景只保留真实太阳方向的主光；地球使用独立海陆粗糙度图，避免颜色图直接驱动的针状高光。
- 太阳对流、地球云层、金星超自转和四颗巨行星纬向气流的视觉速度与形变幅度提高；土星环粒子角速度提高，仍保持按半径差速。
- 木星不再绘制程序化红色螺旋。大红斑直接保留高清底图中的扁椭圆和自然云纹，仅在局部施加极小切向平流与亮度细节；周围云带承担主要动态。进入木星近景时相机选择可见大红斑的半球，并保留昼夜明暗。
- 点击任意标签或行星本体时，会先把该天体写入概览中心锁定，再进入近景；退出近景后选择器和相机仍以该天体为中心。滚轮与右键不会解锁，规则仍是只有左键平移才切换自由浏览。

## 2026-09-22 真实光照、卫星与近景安全边界

- 移除跟随相机的白色补光，修复高光永远钉在画面中央的问题；近景只使用由太阳与目标真实相对位置计算的方向光。地球颜色贴图不再直接充当粗糙度，改由海陆分类生成保守粗糙度并配合独立法线。
- 地球云层改用真实云图独立平流，暗面以 NASA Black Marble 2016 夜间辐亮度观测生成暖色灯光；灯光只在背阳半球出现。大气着色使用视线、法线与太阳方向共同计算蓝色散射和终止线暖色。
- 增加月球、木卫一、木卫二、木卫三、木卫四。卫星由 Astronomy Engine 的月球/木星卫星状态计算，保留父天体真实相对距离；月球使用 NASA LRO 色彩与 LOLA 高程资源，卫星轨道比行星轨道更细更淡。
- 视角中心改为地月系统、木星系统等分组菜单，卫星可直接锁定、追焦和查看详情。标签在系统尺度可读时才显示，避免太阳系全景拥挤。
- 轨道在深度近景随相机距离连续淡出，消除旋转时轨道穿过球体造成的斜线震颤。概览和近景最大放大均按目标圆盘与可用视口动态限制，不再允许相机贴入表面。
- 追加 Unreal Engine 原生迁移评估：物理核心与数据契约可复用，Three.js、GLSL、DOM/CSS 和控制器需按 UE5 C++、Material/Niagara、UMG/CommonUI 与 Enhanced Input 重建。
