# 检查与修正记录（2026-09-23）

## 修正的问题

1. **近景切换天体后锁定中心错误**：在 A 的近景中点击 B，概览锁定仍停留在 A。现在每次标签/目录追焦都会把锁定改为目标天体（`focusBody`）。
2. **近景切换覆盖概览视角**：近景→近景时误把近景机位存成“概览机位”，返回后停在极近处。现在只有真正从概览出发时才记录概览机位（`beginCameraTransition`）。
3. **概览深度精度**：自由浏览时近裁剪面固定为 1e-8、远裁剪面 ≥1600，深度缓冲几乎无精度。改为按最近可见天体表面动态推远近裁剪面（`overviewNearPlane`）。
4. **触屏单指旋转会解除锁定**：解锁判断只接受鼠标/触控笔左键平移。
5. **近景平移后缩放错位**：切换增强与窗口缩放时，相机围绕当前目标（增强切换时连同目标一起围绕原点）缩放。
6. **增强模式下切换轨道显示时状态文字错误**：统一由 `viewModeText()` 生成。
7. **同步自转卫星不朝向母星**：月球与伽利略卫星改为经度 0 始终朝向母星（`facingAngle`）。
8. **目录搜索**：目录条目加入英文名，可按 “Earth”“Io” 搜索；离开“天体”工作区时清除过滤。
9. **C 内核坐标约定**：参考初态由渲染用 XZ 平面（在 +Y 为北的约定下为逆行）改为 J2000 黄道 XY 平面、绕 +Z 顺行，与星历适配层一致。
10. **C 无质量天体**：质量 ≤ 0 的天体改为测试粒子，受引力但不施力；日地两体场景中其余行星由“卡在太阳内部的静止点”改为绕日圆轨道测试粒子。
11. 删除运行时从未执行的增强卫星缩放分支及未使用的 `enhancedSatelliteOrbitScale`、`speedInDaysPerSecond`。

更正：上一轮检查曾报告 `.model-scene-transition` 样式缺失，实为搜索输出被截断的误报，样式一直存在（已并入新样式表）。

## 界面重设计

参考 apple.com 深色产品页（见 ADR-007）：重写 `web/index.html` 与 `web/src/styles.css`，合并原先三层相互覆盖的样式。播放/暂停、“现在”、速度、比例分段控件和纯净视图集中到底部控制栏；返回概览按钮移到场景标题上方；工作区设置使用开关样式。

## 验证

- `npm run check` 通过：12 项 Web 回归（新增同步自转朝向测试）、C 回归（新增顺行方向与测试粒子测试）、TypeScript 检查与生产构建。
- 浏览器（1024×768 与 390×844）实测：地球近景→目录切换火星→返回，锁定为火星且回到原概览距离；增强画廊、天体搜索（英文名）、显示开关、暂停状态、窄屏布局与地球近景；控制台无错误。
- 未验证：真实触屏设备、低端 GPU、Safari/Firefox。深度精度改进按公式推导，未做逐帧对比。
