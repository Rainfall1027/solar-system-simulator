# 转场动画优化记录（2026-09-24）

目标：点击标签放大、天体间切换、真实比例 / 视觉增强切换保证丝滑流畅。

## 发现的问题

1. 天体间切换分四段（后拉 1.35 s → 回太阳 0.8 s → 停 0.28 s → 移到目标 0.8 s → 停 0.12 s → 放大 1.6 s），约 5 秒，每段都减速到零，走走停停。
2. 追焦的放大段在 25% 进度处以最大速度突然开始（ease-out 起点斜率非零），有“顿挫”。
3. 转场期间强制关闭表面特效，到达瞬间云层、夜光、太阳对流、气流一齐跳出。
4. 切入近景时其余天体、小行星带、柯伊伯带 / 奥尔特云标记、太阳星芒在单帧内消失（返回时单帧出现）。
5. 比例切换：点击时截取两帧画面（GPU 回读）并同步重新采样 13 条轨道（约 36 ms），先卡顿再播放两张静止截图左右滑动，期间场景冻结、分辨率降为 80%。
6. 首次进入土星近景时编译阴影着色器，单帧约 38–51 ms；首次显示云层 / 夜光时才上传大纹理。
7. 切入近景的那一帧重建详情卡片 DOM，触发半透明侧栏重排。

## 改动

见 `docs/decisions.md` ADR-009。代码：`web/src/main.ts`（飞行、形变、预热）、`web/src/view-math.ts`（`smoothZoomPath`、`dwellAtApex`、`flightDurationSeconds`）、`web/src/surface-effects.ts`（特效渐变）、`web/src/space-effects.ts`（带状结构透明度）。

## 实测（Playwright，60 fps 固定步进；主线程 JS 时间，不含 GPU）

| 转场 | 时长 | 中途停顿帧 | 最大逐帧速度突变 | 最长帧 |
|---|---|---|---|---|
| 概览 → 地球 | 2.03 s | 0 | 2.6% | 3.1 ms |
| 地球 → 海王星 | 2.80 s（原约 5 s） | 0* | 9.3%（改前 26.8%） | 2.2 ms |
| 火星 → 木星 | 2.63 s | 0* | 9.3% | 2.5 ms |
| 木星 → 木卫一 | 1.53 s | 0* | 7.5% | 5.3 ms |
| 返回概览 | 1.8–2.1 s | 0 | 2.4–3.4% | ≤ 6.7 ms |
| 真实 → 增强形变 | 1.18 s | 0 | 4.3% | 6.9 ms |
| 进入土星近景 | — | — | — | 5 ms（改前 38–51 ms） |

\* 计数为 1–2 帧的是缩放由“拉远”转为“推近”的顶点瞬间，此时横向平移仍在进行，画面并未停住。
